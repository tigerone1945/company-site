# スカイライン・テクノロジーズ株式会社 コーポレートサイト

事業の輪郭を、コードで描く。

受託開発からクラウド運用、AI活用まで事業の成長を技術で支えるソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」のコーポレートサイトです。

## 概要

- 単一の静的HTMLファイル(`index.html`)で構成されたコーポレートサイトです。
- 外部フレームワークへの依存はなく、HTML / CSS(インラインスタイル)のみで実装されています。
- フォントはGoogle Fonts(Zen Kaku Gothic New / Noto Sans JP)を使用しています。

## ブラウザで開く手順

1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザ(Google Chrome、Safariなど)にドラッグ&ドロップ、または以下のコマンドで開きます。

   ```bash
   open index.html
   ```

   ※ Windowsの場合は `start index.html`、Linuxの場合は `xdg-open index.html` を使用してください。

3. ブラウザ上でサイトが表示されます。
